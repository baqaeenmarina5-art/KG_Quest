# 🗺️ KG Quest — Learn, Play, Explore
### لعبة تفاعلية لرياض الأطفال

لعبة تعليمية تفاعلية (HTML/CSS/JavaScript بدون أي مكتبات خارجية) مبنية بدقة على كلمات وأنشطة كرّاسات
منهاج رياض الأطفال التطوري — الفصل الدراسي الأول والثاني، بالإضافة إلى عالم إثرائي للرياضيات.

## 🎮 جرّبها مباشرة
افتح `index.html` في أي متصفح، أو فعّل **GitHub Pages** من إعدادات المستودع
(Settings → Pages → Deploy from branch → `main` / root) وستحصل على رابط مباشر للعبة.

## ✏️ كيف أضيف سؤالًا أو لعبة جديدة؟

كل بيانات الأسئلة موجودة داخل `js/app.js`، منظّمة على شكل دوال `start...()` لكل لعبة
(مثل `startAlefQuiz()`، `startSenses()`) تستدعي أحد المحرّكات العامة:

- `runQuiz(rounds, gameKey, icon, title)` — أسئلة اختيار من متعدد / صح وخطأ
- `runMatch(pairs, gameKey, icon, title, prompt)` — مطابقة عمودين
- `runCount(rounds, gameKey, icon, title, choicesPool)` — عدّ العناصر
- `runSort(items, gameKey, icon, title, labelA, emojiA, labelB, emojiB)` — تصنيف ثنائي
- `runOrder(rounds, gameKey, icon, title)` — ترتيب تسلسلي
- `runPattern(rounds, gameKey)` — إكمال الأنماط

لإضافة سؤال جديد لأي لعبة، عدّل مصفوفة `rounds`/`items`/`pairs` داخل الدالة المناسبة في `app.js`،
ثم أضف زر اللعبة في `index.html` إذا كانت لعبة جديدة بالكامل مع استدعاء الدالة المطابقة.

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد إليه.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر **Deploy from a branch**، الفرع `main`، والمجلد `/ (root)` — أو اترك ملف
   `.github/workflows/deploy.yml` يقوم بالنشر تلقائيًا عبر GitHub Actions عند كل `push` لفرع `main`.
4. بعد دقيقة أو دقيقتين ستحصل على رابط مثل: `https://<username>.github.io/<repo-name>/`.
